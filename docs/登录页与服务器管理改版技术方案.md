## 1. 背景与目标

### 1.1 用户反馈的痛点

1. **整个登录页面没有大厂设计感**——一屏塞了「选配置/选协议/填表单/配证书」四件事，信息层级混乱。
2. **设置中的已保存配置**希望设计成一个二级页面，里面是一张张卡片。

### 1.2 代码实证的根因

| 根因 | 证据 |
|---|---|
| **一屏任务过载**：Logo → 已保存配置 chips → 服务器类型 chips → 4 输入框 → 2 开关 → 高级选项 → 登录按钮，全部平铺在单页 | `login_screen.dart:646-1047`（build 内单列 28 个 children） |
| **工程选项裸露在表单主流程**：legacy 认证、自签名证书两个开关与用户名密码平级展示 | `login_screen.dart:897-929`、`:931-961` |
| **服务器类型选择噪音大**：Subsonic/Jellyfin/道理鱼三个描边 chips，用户不关心协议名 | `login_screen.dart:1487-1591`（`_ServerFamilyToggle`） |
| **输入框为 Material Outlined 描边**，偏后台管理工具感，非 iOS 分组卡片风格 | `login_screen.dart:781-783`、`:846-848`、`:883-885` |
| **已保存配置用 InputChip**：删除叉与点击连接打架，配置多时换行成坨、无主次 | `login_screen.dart:1442-1471`（`_SavedProfilesSwitcher`） |
| **已保存配置内嵌在服务器管理 Tab 内**，配置多时把设置页拉得很长 | `settings_server_tab.dart:293-479`（`_buildSavedProfilesSection`） |

### 1.3 目标

- **登录页两步引导**（对标 Plex/Jellyfin 引导式 wizard + Netflix 选人页）：第一步「我的服务器」卡片列表（选已有 / 添加新服务器）；第二步连接表单（地址 + 凭据），工程选项全部收敛进高级折叠区
- **已保存配置独立二级页**：设置 → 服务器管理 内只留一行入口，点击进入卡片列表二级页；登录页复用同一套卡片组件
- **Apple Music 视觉风**：浅色分组卡片、无边框填充式输入框、克制品牌区、单一主 CTA

## 4. 设计方案

### 4.1 整体流程（两步引导）

```
┌─ 登录网关页（Step 1）────────────────────────┐
│  品牌区（logo + App 名）                      │
│  「我的服务器」                              │
│  ┌──────────────────────────────────────┐   │
│  │ [徽标] 家里NAS        ● 当前连接      │   │
│  │        nas.lan:4533 / admin          │   │
│  └──────────────────────────────────────┘   │
│  ┌──────────────────────────────────────┐   │
│  │ [徽标] 公司Jellyfin                   │   │
│  │        jellyfin.work / chengsi       │   │
│  └──────────────────────────────────────┘   │
│  ┌─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐   │
│  │      ＋ 添加服务器                     │   │
│  └─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘   │
└──────────────────────────────────────────┘
                │ 点「+」/ 空态时点主按钮
                ▼
┌─ 连接表单页（Step 2）───────────────────────┐
│  （标题：添加服务器 / 编辑服务器）           │
│  ┌ 连接 ──────────────────────────────┐    │
│  │ [无边框输入] 服务器地址              │    │
│  │ [无边框输入] 局域网地址（可选）       │    │
│  │ 服务器类型        Subsonic ＞       │    │
│  └────────────────────────────────────┘    │
│  ┌ 账号 ──────────────────────────────┐    │
│  │ [无边框输入] 用户名                 │    │
│  │ [无边框输入] 密码（眼）              │    │
│  └────────────────────────────────────┘    │
│  ▾ 高级选项（legacy 认证 / 自签名证书 /    │
│      TLS 证书 / 客户端证书 / 配置名称）     │
│  ┌──────────────────────────────────────┐   │
│  │             连 接                     │   │
│  └──────────────────────────────────────┘   │
└──────────────────────────────────────────┘
```

**状态与入口矩阵**：

| 入口 | 行为 |
|---|---|
| 首次启动（无配置，root route） | 登录网关页大品牌区 + 全宽「添加服务器」主按钮（`login_screen.dart:646-696` 品牌区复用，InputChip 区不渲染） |
| 有已保存配置（root route） | 登录网关页 → 小品牌区 + 卡片列表 + 虚线「＋添加服务器」卡 |
| 点已保存卡片 | 非当前连接：确认弹窗（复用 `settings_server_tab.dart:413-441` 逻辑）→ `switchProfile`；当前连接：直接进编辑表单 |
| 设置 → 已保存配置二级页 → 点卡片 | 同上（编辑进表单、非当前切换） |
| `LoginScreen(initialConfig:)`（设置页编辑入口） | **跳过 Step 1**，直接进 Step 2 表单页，预填（`_prefillFromConfig` 逻辑保留），标题「编辑服务器」，保存后 pop 返回 |

### 4.2 页面一：登录网关页（新建，替换原单页登录）

- 路由文件：新建 `screens/server_gateway_screen.dart`（或直接重构 `login_screen.dart` 为网关页 + 表单页两个类，同文件 1592 行过大，**拆文件**更合理）
- 结构：
  - 顶部品牌区（无配置时居中大 logo + App 名 + 副标题；有配置时压缩为顶部小 logo + 标题「我的服务器」）
  - 服务器卡片列表（复用 `ServerProfileCard`，见 4.5）
  - 底部「＋添加服务器」虚线卡片（Material 风格 dashed 或浅色圆角卡 + 主色 + 图标）
  - 空态：大 logo + 引导文案 + 全宽胶囊「添加服务器」主按钮
- 删除交互：卡片操作区提供删除（直接删 或 滑动删除，见 §5 待确认项）

### 4.3 页面二：连接表单页（Step 2）

- 新建 `screens/server_form_screen.dart`（从旧 `login_screen.dart` 迁移表单逻辑，复用 `_login()`、`_categoriseError`、`_buildErrorCard`、证书选择逻辑）
- 分组卡片（Apple Music inset grouped）：
  - **连接组**：服务器地址、局域网地址（可选）、`服务器类型` 列表项 → 点击弹底部选择器（自动 / Subsonic / Jellyfin / 道理鱼，默认**自动**）
  - **账号组**：用户名、密码（带可见性切换）
  - **高级选项**（折叠）：legacy 认证开关、自签名证书开关、自定义 TLS 证书、客户端证书（含密码）、配置名称 —— 全部从裸露出收敛到这里
- 底部全宽胶囊主按钮「连接」，loading 态复用现有 `isBusy` 逻辑
- 探测展示：连接时 `pingWithError()` 已返回 `serverType/serverVersion`，成功后可于表单顶部或服务器类型行显示「已连接：Jellyfin 10.8.0」；服务器类型选「自动」时，若探测结果与所选不符，以探测结果为准并提示（不阻断）

### 4.4 已保存配置独立二级页（设置内）

- `settings_server_tab.dart:293-479` 的 `_buildSavedProfilesSection` 整体替换为一行入口：

```
┌ 已保存配置 ────────────────────────────┐
│ [列表图标] 已保存配置          N ＞     │
└────────────────────────────────────────┘
```

- 点击 push `SavedProfilesScreen`（新建，AppBar「已保存配置」+ `SettingsSubPage` 或自带 AppBar）
- body = 卡片列表（同 `ServerProfileCard`）+ 空态引导 + 「＋添加服务器」入口
- 该二级页与登录网关页共用卡片组件，仅外壳不同（一个带返回 AppBar、一个无返回按钮）

### 4.5 共享组件 `ServerProfileCard`（新建 `widgets/server_profile_card.dart`）

```dart
ServerProfileCard(
  profile: ServerConfig,
  isActive: bool,          // 当前连接 → 右侧绿点徽标 + 名称主色加粗
  onTap: VoidCallback,     // 当前连接 → 编辑；非当前 → 确认切换
  onQr: VoidCallback?,     // 二维码分享
  onEdit: VoidCallback?,
  onDelete: VoidCallback?,
)
```

- 视觉：圆角 16、白 / `darkSurface`、无阴影（iOS 卡片）；左侧**家族色图标块**（Subsonic 主色 / Jellyfin 紫 / 道理鱼绿，32×32 圆角 8 淡底图标，沿用 `settings_root_screen.dart:312` `_leadingIcon` 风格）；主标题 = 配置名称（无名称时 `username@host`，沿用 `settings_server_tab.dart:351-353` 逻辑）；副标题 = URL + 用户名；右侧操作区 = qr / 编辑 图标 +（可选）删除

### 4.6 视觉规范（Apple Music 风）

| 元素 | 规范 |
|---|---|
| 背景 | 沿用 `lightBackground #F2F2F7` / `darkBackground #000000`（不动） |
| 分组卡片 | 白 / `darkSurface`，圆角 16，无阴影，组间距 24，卡片间距 12 |
| 输入框 | 填充式：圆角 12、背景 `#F2F2F7`（浅）/ `#1C1C1E`（深）、无描边边框；去掉 `OutlineInputBorder`（`login_screen.dart:781-783` 等） |
| 主按钮 | 全宽、高 50、圆角 25（胶囊）、`appleMusicRed` 主色、白色文字、loading 转圈 |
| 品牌区 | 无配置：居中大 logo + `displayMedium` App 名 + 副标题；有配置：顶部小 logo（64）+「我的服务器」标题 |
| 家族徽标色 | Subsonic `#6366F1`、Jellyfin `#A970FF`、道理鱼 `#34C759`（登录网关与二级页共用一张映射表） |
