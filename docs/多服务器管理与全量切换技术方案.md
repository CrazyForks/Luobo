# 多服务器管理与全量切换技术方案

> 版本：v1.0（2026-08-10）
> 范围：修复「多个服务器登录后展示/切换/全量切换」链路，覆盖 navidrome 与道理鱼（daoliyu）互切
> 前置：docs/道理鱼接入技术方案.md（双协议适配）

---

## 1. 问题背景

用户诉求（2026-08-10 会话）：

1. **多个服务器登录后在哪里展示？** —— 设置-服务器管理应列出已保存的所有服务器（含当前登录的），可编辑、可分享二维码、可切换。
2. **如何切换服务器？** —— 在服务列表中点击非当前服务器 → 确认 → 全量切到该服务器（接口、数据、封面全部跟随）。
3. **登录成功后所有数据、接口要全量切换** —— 登录/切换后不得再有任何请求打到旧服务器。

### 1.1 诊断日志证据（luobo_diagnostics_1786101749903.txt，2026-08-07 抓取）

切到道理鱼后（19:21:35，`net.urlResolved host=https://daoliyu... switched=true`）：

| 时间 | 请求 | 结果 | 根因 |
|---|---|---|---|
| 19:22:05/10/15/20/25 | `https://navidrome.../share/img/eyJ...?size=600` | 404 ×5 | 持久化队列歌曲的 `coverArt` 字段是**绝对 URL**（旧服务器 share/img 地址），切服后仍在请求 |
| 19:21:58 | `GET daoliyu/rest/getAlbum?id=6kTFVcUOWQzToJW3xqXdSn` | 404 | Navidrome 专辑 ID 打新服务器 —— **LibraryProvider 旧数据未清** |
| 19:22:10 | `GET daoliyu/rest/getArtist?id=2KFGURzjQyPNS4sZ6a5Ct6` | 404 | Navidrome 艺人 ID —— 同上 |
| 19:22:01 | `stream songId=klJut7o6ACbZWXBnQLp278` + lyrics 404 | 404 | **冷启动恢复了 30 首 Navidrome 队列**，切换后仍在播旧 ID |

**结论**：接口层切换（`activeBaseUrl`/JWT）已通；残留问题在**数据层**——队列持久化、LibraryProvider 内存与 prefs 缓存、封面绝对 URL 未随服务器隔离/清理。

## 2. 现状代码分析

| 模块 | 现状 | 问题 |
|---|---|---|
| `AuthProvider.login()` | 成功→`saveProfile` + `_notifyServerSwitched()` | ✅ 主流程已通 |
| `AuthProvider.switchProfile()` | `configure` + `resolveActiveUrl` + `_verifyConnection` | ⬜ **daoliyu 不调 `loginToApi()`** → JWT 空，歌词/随机歌降级 |
| `main.dart` `onServerSwitched` | `player.clearQueue()` + `homeRec.clearCaches()` | ⬜ **没清 LibraryProvider**（内存+prefs+DB） |
| `LibraryProvider` | `_artists/_recentAlbums/_playlists/_cachedAllSongs/_starred` 等 + prefs `cached_playlists/cached_artists` + DB | ⬜ 切服后旧服务器数据残留在内存与 prefs；`cached_playlists/cached_artists` 是**全局键**不随服务器隔离 |
| `PlayerProvider._restoreQueueState` | 冷启动无条件恢复 `persistent_queue` | ⬜ 队列**不校验服务器**；封面存绝对 URL |
| `SubsonicService.getCoverArtUrl()` | 直接 `$activeBaseUrl/rest/getCoverArt?id=$coverArt` | ⬜ `coverArt` 是绝对 URL 时拼出跨服 URL（旧服务器 share/img 404） |
| `QuickAccessGrid` | `Image.network(widget.coverArt!)` 直用原始字段 | ⬜ 不经过 `getCoverArtUrl`，绝对 URL 直接外发 |
| `_daoliyuTrackToSong` | `coverArt: t['coverArt']`（/api 层 `path=` 形式） | ⬜ 与 Subsonic `getCoverArt?id=album:alb_xxx` 不匹配 |

## 3. 目标流程

### 3.1 多服务器展示

- 入口：**设置 → 服务器管理**（`SettingsServerTab`，`settings_root_screen._serverCard` 已接 `l10n.serverManagement`）。
- 页面含「已保存的服务器」区块：每项显示名称/地址/当前勾选，trailing 提供 **二维码 + 编辑**，底部 **添加服务器**。
- 空态提示 `noSavedProfiles`。

### 3.2 切换服务器

- 点击非当前服务器项 → 确认弹窗（`switchProfileConfirmation`）→ `playerProvider.stop()` → `authProvider.switchProfile(profile)`。
- `switchProfile` 内部：`_verifyConnection`（含封面缓存 key 重注册）→ **daoliyu 补 `loginToApi()`** → `_notifyServerSwitched()`。

### 3.3 登录/切换后全量切换

`onServerSwitched` 回调升级为（main.dart）：

```
player.clearQueue()            // 停止播放 + 清队列持久化
homeRec.clearCaches()          // 清首页每日/探索缓存
library.resetForServerChange() // 清内存列表 + prefs 缓存 + DB，重初始化拉新服务器数据
```

## 4. 改动清单

### P1 — LibraryProvider：服务器级重置 + 缓存隔离

文件：`lib/providers/library_provider.dart`

- 新增 `Future<void> resetForServerChange()`：
  1. 清空内存列表：`_artists/_recentAlbums/_frequentAlbums/_newestAlbums/_randomAlbums/_playlists/_randomSongs/_genres/_richGenres/_starred/_cachedAllAlbums/_cachedAllSongs/_cachedPlaylists/_topArtistsCache`；
  2. 删除 prefs 键：`cached_playlists` / `cached_artists` / `last_cache_update`；
  3. `_db.clearAll()`（清本地曲库 DB）；
  4. `_isInitialized=false`、`_error=null`、`notifyListeners()`；
  5. `await initialize(force: true)` 从新服务器全量拉取。
- 说明：`cached_playlists/cached_artists` 保持全局键但**切换时显式删除**（同服务器冷启动仍命中缓存，跨服务器不串数据）。

### P2 — PlayerProvider：队列按服务器校验 + 封面 URL 兜底

文件：`lib/providers/player_provider.dart`

- 新增 `static const _keyQueueServer = 'persistent_queue_server'`。
- `_saveQueueStateImmediate()`：写入 `_keyQueueServer = _subsonicService.coverCacheServerId`。
- `_restoreQueueState()`：读取 `_keyQueueServer`；若 `saved != '' && saved != coverCacheServerId && coverCacheServerId != ''` → 清空持久化队列并 return（不恢复旧服务器队列）。
- 新增 `void validateQueueForServer()`：冷启动时 `coverCacheServerId` 可能尚未配置（AuthProvider 异步加载），由 **MainScreen.initState** 在配置就绪后补一次校验。

### P3 — getCoverArtUrl 绝对 URL 防护

文件：`lib/services/subsonic_service.dart`

- `getCoverArtUrl()` 开头（jellyfin/youtube 分支后）：
  - `coverArt` 以 `http://` 或 `https://` 开头 → `Uri.parse`：
    - host 与当前 `activeBaseUrl` 一致 → 原样返回（跨 LAN/远程同服可命中）；
    - 不一致（旧服务器）→ 返回 `''`（占位图，不再外发跨服请求）。
- `_daoliyuTrackToSong()`：`coverArt` 改为优先 `album['id'] != null ? 'album:${album['id']}' : t['coverArt']`，与 Subsonic `getCoverArt?id=album:alb_xxx` 对齐。

### P4 — switchProfile 补 daoliyu JWT 登录

文件：`lib/providers/auth_provider.dart`

- `switchProfile()` 在 `_verifyConnection()` 成功后：
  - 若 `profile.serverFamily == 'daoliyu'` → `await _subsonicService.loginToApi()`；
  - 把 `apiToken/userId` 写回 `_config` → `saveServerConfig` + `saveProfile`。

### P5 — main.dart 全量切换接线 + MainScreen 队列校验

文件：`lib/main.dart`、`lib/screens/main_screen.dart`

- `main.dart` `onServerSwitched`：追加 `library.resetForServerChange()`（`context.read<LibraryProvider>()`）。
- `main_screen.dart` `initState`：在 `libraryProvider.initialize()` 附近追加 `playerProvider.validateQueueForServer()`。

### P6 — QuickAccessGrid 封面走 getCoverArtUrl

文件：`lib/widgets/quick_access_grid.dart`

- `_QuickAccessItem` 的 `Image.network(widget.coverArt!)` 改为经 `SubsonicService.getCoverArtUrl(coverArt)` 取 URL（空则占位），消除绝对 URL 直发。

## 5. 验证清单（真机）

1. 从未登录过 → 冷启进登录页（回归不变）。
2. 登录 navidrome 后，设置-服务器管理显示该服务器（勾选态）。
3. 添加道理鱼配置登录成功 → SnackBar 提示 → 首页（回归不变）。
4. 设置-服务器管理显示 **两台** 服务器；点击道理鱼 → 确认 → 全量切换：
   - 首页/音乐库/搜索/播放全部走 daoliyu（诊断日志无 navidrome host 请求）；
   - 无 `getAlbum/getArtist 404`（旧 ID 请求）；
   - 封面正常（无 `share/img` 404）；
   - 队列被清空，不播旧服务器歌曲。
5. 再切回 navidrome → 同理全量切换，道理鱼数据不残留。
6. 冷启动（上次在 daoliyu）→ 不恢复 navidrome 队列；音乐库显示 daoliyu 数据。
