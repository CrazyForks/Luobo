# Luobo 设置页重构技术方案

> 状态：已实施 P0-P2（2026-08-05，analyze 0 error，测试回归中，待真机验证）；P3 视觉统一待排期
> 范围：设置页**导航结构**重构（8 Tab → 单列表 + 二级页）+ 信息架构归位（支持/关于去重、诊断收敛）+ 视觉统一 + 版本号硬编码修复
> 设计约束：不新增设置项、不改业务逻辑、不改存储结构；现有 8 个 tab 的「身体」尽量 1:1 复用为二级页；导航骨架新建文件替换，旧 `settings_screen.dart` 保留不删（可一行回退）；文档先行，用户确认后开工
> 实施进度：✅ P0 骨架（根页/子页薄壳/转码拆分）→ ✅ P1 版本修复 → ✅ P2 归位收敛（评分迁根页、诊断收敛、l10n）→ ⬜ P3 视觉统一（SettingsTile 替换各页行组件，独立一轮）

## 1. 背景与目标

### 1.1 用户反馈的痛点

设置界面用起来不舒服、设计不合理：入口不可预览、要横滑翻找、不知道某个选项在哪个 tab 里。

### 1.2 代码实证的根因

| 根因 | 证据 |
|---|---|
| **8 个 Tab 平级横滑，信息不可预览**——这是浏览器标签页形态，不是设置页形态；用户必须逐个切 tab 才知道里面有什么 | `settings_screen.dart:30`（`TabController(length: 8)`）、`:52-102`（TabBar）、`:107-116`（TabBarView 8 个 body） |
| **诊断被放成「一等公民」**——开发者工具与「支持/关于」平级、带图标占一个 tab | `settings_screen.dart:99-101, 115`（DiagnosticsPage 作为第 8 个 tab） |
| **支持与关于内容重复**——关于 tab 里已有评分+打赏+Discord，支持 tab 又是同样的三样 | `settings_about_tab.dart:231-257`（支持 section） vs `settings_support_tab.dart`（整页心形/捐款/Discord 落地页，**已随去原项目化删除**） |
| **同一屏四种视觉语言**：彩色渐变图标块（播放/存储）、淡色图标块（服务器）、渐变图标（AI tab）、裸图标（部分行）混用 | `settings_playback_tab.dart:158-171`（渐变）、`settings_server_tab.dart:144-154`（`withValues(alpha:0.15)` 淡底） |
| **开关组件混用**：`CupertinoSwitch`（trailing）与 `SwitchListTile`（Material 开关）并存 | `settings_playback_tab.dart:334` vs `settings_storage_tab.dart:293` |
| **分隔线不统一**：`_buildDivider(left:56)` 与裸 `Divider(indent:16/64)` 并存 | `settings_storage_tab.dart:225-233` vs `settings_about_tab.dart:148` vs `settings_ai_playlist_tab.dart:133` |
| **行尾交互过载**：同屏出现 DropdownButton 挤在行尾、inline Slider、跳二级页、开关四种交互；Dropdown 在 ListTile 尾部易误触 | `settings_playback_tab.dart:177, 278`（DropdownButton）、`:239`（subtitle Slider） |
| **版本号硬编码过期**：pubspec 已到 `1.1.6+1`，关于页仍显示 `1.0.13` | `settings_about_tab.dart:57`、`:91`（changelog URL）；`update_service.dart:48`（`currentVersion = '1.0.13'`，唯一来源也应同步） |

### 1.3 目标

- **导航对标大厂**：Apple Music（iOS 设置）/ 网易云 / QQ 音乐的设置页模式 = 单列表分组滚动 + 入口行 push 二级页，扫一遍可见全部入口
- **信息归位**：账号/服务器置顶、播放/存储/显示分组、支持与关于去重、诊断收敛、版本号作为 footer
- **工程原则**：导航骨架新建文件替换（入口 `library_screen.dart:1136` / `desktop_navigation_sidebar.dart:53`）；tab 身体 1:1 复用不改逻辑；文档先行，用户确认后开工

### 2.2 入口挂载点

- 移动端：`library_screen.dart:1136`（`NavigationHelper.push(context, const SettingsScreen())`）
- 桌面端：`desktop_navigation_sidebar.dart:53`（`MaterialPageRoute` push `SettingsScreen`）

两个入口都指向 `SettingsScreen` —— 新根页只需替换这一处组件名（新建 `settings_root_screen.dart`，入口改为指向它），旧 `settings_screen.dart` 保留。

### 2.3 其他

- l10n：`tabPlayback/tabStorage/.../tabDiagnostics` 已存在（`app_en.arb:924-931`、`app_zh.arb:712-719`），重构后多数不再使用，**保留不删**（其他语言文件同样引用）；新文案（如「下载与存储」组标题）需新增后 `flutter gen-l10n`
- Provider：`AuthProvider`/`PlayerProvider`/`TranscodingService` 等注册于 `main.dart` 顶层，二级页 push 后照常可用，无需改动
- 版本：`pubspec.yaml:14` = `1.1.6+1`；`update_service.dart:48` 有唯一版本常量；**未引入 `package_info_plus`**

## 3. 大厂对标分析

| 维度 | Apple Music（iOS 设置→音乐） | 网易云 | QQ 音乐 | Luobo 现状 |
|---|---|---|---|---|
| 导航结构 | 单列表分组滚动，无 tab，有搜索 | 单列表分组滚动 | 单列表分组滚动 | ❌ 8 Tab 横滑 |
| 行组件 | 图标+标题+右侧 值/开关/chevron 三选一 | 同左 | 同左 | ⚠️ 四种交互混排、Dropdown 挤行尾 |
| 层级 | 多选型选项 push 子页单选 | push 子页 | push 子页 | ⚠️ inline 展开（`if` 条件块）+ Dropdown |
| 账号/服务器 | 置顶（头像/账户） | 置顶（账号与安全） | 置顶 | ✅ 已近似（服务器 tab） |
| 破坏性操作 | 底部红色 | 底部红色 | 底部红色 | ✅ 已有（清除缓存/退出登录红字） |
| 版本号 | 列表底部 footer | 底部 footer | 底部 footer | ❌ 占一行正文且硬编码过期 |

**三家共性**（本次重构直接采用）：
1. 根页是一条**完整的分组列表**，扫一眼可见全部入口，无 tab
2. 行组件**解剖结构统一**：左侧图标 → 标题 → 右侧「当前值 / 开关 / chevron」三选一；chevron 表示「进去还有子页」
3. 层级靠 **push 二级页**，不在根页做 inline 展开
4. 破坏性操作红色置底
5. 版本号是**页面 footer**，不占正文行

## 4. 新结构设计

### 4.1 目标信息架构（根页 → 二级页映射）

```
设置（根页，单列表分组）
│
├─ 账号与服务器                    ← 置顶，信息卡展示当前连接（类型/版本/URL/用户名）
│   ├─ 服务器设置        → SettingsServerTab（配置档案/音乐文件夹/Jukebox）
│   └─ 退出登录(红色)               ← 从 server tab 上移到根页底部，见 §4.2
│
├─ 播放与音质
│   ├─ 播放设置          → SettingsPlaybackTab（自动DJ/无缝/淡入淡出/歌词/音量平衡，已拆出转码）
│   └─ 音质与流媒体      → SettingsStreamingTab（转码开关/智能转码/码率/格式）
│
├─ 下载与存储
│   └─ 下载与存储        → SettingsStorageTab（缓存/清理/离线下载/本地音乐/BPM）
│
├─ 显示与外观
│   └─ 显示与外观        → SettingsDisplayTab
│
├─ AI 智能
│   └─ AI 歌单与知识库   → SettingsAiPlaylistTab
│
├─ 支持与帮助                    ← 合并：从 about tab 移入评分/反馈，去掉重复
│   ├─ ~~支持这个 App~~      ❌ 已删除（SettingsSupportTab 随去原项目化移除，捐赠/社区入口不再提供）
│   └─ 评分 Luobo（原在 about tab:239）
│
└─ 关于
    ├─ 版本 / 平台 / 开发者 / 开源链接 / 更新日志 / 隐私与匿名统计
    └─ 诊断（收敛到组内底部）     → DiagnosticsPage（自带 AppBar，直接 push）
                                       └─ 底部 footer：版本号（动态读取）
```

要点：
- **根页信息密度低、一眼扫完**；每个入口 chevron 明确「进去还有内容」
- **8 个 tab body 一个不丢**，全部作为二级页复用到（映射表见 §2.1），业务逻辑零改动
- **支持与关于去重**：评分/打赏/反馈只留一份（支持页）；关于页只留信息类
- **诊断收敛**：从「第 8 个 tab」降级为「关于组底部一行」（仍是一级可达，一个 push）

### 4.2 根页账号与服务器组（置顶信息卡）

- 信息卡复用 `settings_server_tab.dart:30-40` 的取值逻辑（`authProvider.config?.serverType/serverVersion/serverUrl/username`），未连接时显示「未连接」
- 卡片点击 → 服务器设置子页
- **退出登录保持红色、置于根页底部**（大厂惯例：破坏性操作在页面底部，而非中间）

### 4.3 子页复用方案（零逻辑改动）

新建薄壳 `SettingsSubPage`（`lib/widgets/settings_sub_page.dart`）：

```dart
class SettingsSubPage extends StatelessWidget {
  final String title;
  final Widget body;   // 现各 Tab 组件直接传入
  ...
  // Scaffold + AppBar(返回键) + body
}
```

- 各 tab 组件（`SettingsPlaybackTab` 等）**保持 `ListView` 身体不变**，由壳提供 AppBar 返回
- **唯一的结构性拆分（已确认）**：把 `settings_playback_tab.dart:609-897` 的转码 section（`_buildTranscodingSection` + 智能转码 help 弹窗）整体搬移到新文件 `settings_streaming_tab.dart`，作为「音质与流媒体」子页；播放 tab 移除该段，其余逻辑不动
- `DiagnosticsPage` 自带 AppBar，不套壳，直接 `NavigationHelper.push`
- 唯一例外的内容调整在 P2：`settings_about_tab.dart` 移除「支持」section（`231-257`）、修复版本号

### 4.4 统一行组件 `SettingsTile`（P3，样式收敛）

新建 `lib/widgets/settings_tile.dart`，统一三处解剖结构：

```dart
class SettingsTile extends StatelessWidget {
  final IconData icon;
  final Color iconColor;          // 方案见下
  final String title;
  final String? subtitle;         // 说明文字（可含 trailing 值）
  final Widget? trailing;         // 三选一：值 / CupertinoSwitch / chevron
  final bool destructive;         // 红色标题（清除缓存/退出登录）
  final VoidCallback? onTap;
}
```

- 行内不再放 DropdownButton/Slider（这些留在二级页内）
- 开关统一 `CupertinoSwitch`（现有主流），废弃 `SwitchListTile`
- 分隔线统一 `left:56` 缩进（对齐现有 `_buildDivider`）

**leading 图标方向（已确认：方案 B，Apple Music / iOS Settings 风格）**：
- 统一「主色 12% alpha 淡底 + 主色单色图标」，破坏性行用红色系
- 说明：Apple Music / iOS「设置」的图标是**单色 glyph + 淡底色**，不是彩色渐变块；用户选择「参考 Apple Music 风格」即对应本方案 B（拍板时曾误以为 A 是 Apple Music 风格，已澄清）

### 4.5 版本号修复（P1 顺手做，零新依赖）

`1.0.13` 三处硬编码收敛为**唯一来源** `update_service.dart:48`：

| 位置 | 现状 | 改法 |
|---|---|---|
| `update_service.dart:48` | `currentVersion = '1.0.13'` | 改为 `'1.1.6'`（版本号唯一真源） |
| `settings_about_tab.dart:57` | `subtitle: '1.0.13'` | 引用 `UpdateService.currentVersion` |
| `settings_about_tab.dart:91` | changelog URL 拼 `v1.0.13` | 引用 `UpdateService.currentVersion` 拼 URL |

不引入 `package_info_plus`（pubspec 目前无此依赖）；如需「永远与 pubspec 同步」留待二期（§8）。

## 7. 决策清单

### 已确认（2026-08-05 全部拍板）

1. **8 Tab → 单列表 + 二级页**（对标三家大厂设置页）
2. **诊断入口**：收敛到「关于」组底部，一级可达、一个 push
3. **leading 图标**：方案 B「主色淡底 + 单色图标」（Apple Music / iOS Settings 风格；已澄清 A/B 对应关系）

6. **导航骨架新建文件替换**，旧 `settings_screen.dart` 保留不删（沿用首页重构验证过的模式）
7. **8 个 tab 身体 1:1 复用为二级页**，业务逻辑零改动（唯一结构改动 = 转码段搬移）
8. **版本号**收敛到 `update_service.dart:48` 唯一来源，同步至 `1.1.6`
