# Luobo - 最佳 Navidrome 客户端

**Luobo**（萝卜）是基于 [Musly](https://github.com/dddevid/Musly) 二次开发的 Navidrome / Subsonic 音乐播放客户端，使用 Flutter 构建，支持 Android 和 iOS。**相比原版 Musly 增加了车载模式、听歌报告、AI 歌单等特色功能，以及大规模国际化适配。**

---

## 🎵 Musly 原生功能

### 核心播放与服务器支持

- **多服务器兼容** — 支持 Navidrome、Subsonic、Airsonic、Gonic、Emby、Jellyfin
- **高品质音乐流** — 智能转码（WiFi/移动网络自适应比特率切换）、ReplayGain、无缝播放（Gapless Playback）
- **转码流完整进度控制** — 转码播放（AAC/MP3/Opus）时进度条正常显示，可随意拖动跳转，不再受限于服务器实时转码
- **音频增强** — 10 波段均衡器、淡入淡出、音高控制、播放速度调节、Dolby Atmos 支持

### 播放器与歌词

- **Apple Music 风格界面** — 现代化设计，暗色/亮色主题自动切换
- **同步歌词显示** — 实时歌词同步、桌面全屏歌词、iOS 动态岛歌词、Android 锁屏歌词、Windows 通知栏歌词
- **播放控制** — 随机播放、循环播放（列表/单曲）、播放队列管理、手势快速切歌

### 离线与本地

- **离线下载** — 并行下载、批量下载、离线播放切换自动降级
- **本地音乐库** — 自动扫描本地文件、与服务器库无缝融合

### 推荐与内容发现

- **智能推荐** — 基于听歌历史的个性化推荐、For You 列表
- **网络电台** — 服务器电台流媒体
- **浏览功能** — 按流派、艺术家、专辑、时间线浏览

### 高级特性

- **多服务器档案** — 快速切换不同服务器账户
- **主题自定义** — 完整的 Now Playing 主题编辑器（5 个编辑 Tab、背景/圆盘/文字/控制/动画）、主题导入导出
- **Android Auto** — 车载系统原生集成
- **Chromecast / UPnP** — 投屏到电视
- **Discord 状态** — 正在播放的歌曲显示在 Discord
- **Jukebox 模式** — 服务器端远程播放控制
- **自动更新** — GitHub 版本检查和应用更新

### 平台覆盖

- 📱 Android 6.0+
- 🍎 iOS 15.0+  
- 🖥️ Windows 10+
- 🐧 Linux（GTK）
- 🍎 macOS 11+

## 🚀 Luobo 差异化功能

### 📍 车载模式（Car Mode）

专为驾驶安全设计的播放界面：
- **3 行大字歌词** — 当前行 + 前后各 1 行，实时同步，驾驶中清晰易见
- **环形进度条** — 可视化播放进度 + 已播/剩余时间
- **屏幕常亮** — 驾驶过程自动禁用息屏
- **下滑返回** — 手势快速返回播放器

**适用场景：** 🚗 开车听歌、🛵 骑车听歌、🏃 跑步健身

---

### 📊 听歌报告（Listening Report）

个人音乐数据分析面板，了解你的听歌习惯：
- **概览统计** — 总听歌时长、播放次数、歌手数、歌曲数
- **完播率分析** — 你有多认真地听完每首歌，配合个性化评语
- **时段偏好** — 早中晚分别喜欢听什么流派、什么歌手
- **排行榜** — 最常听的歌、最常听的歌手、最常跳过的歌
- **单曲循环** — 你最喜欢反复听的歌曲
- **流派分布** — 你的音乐品味占比（自动中英文归一化）
- **新发现** — 最近新喜欢的歌
- **老朋友** — 陪伴你最久的歌手
- **周末对比** — 周末 vs 工作日的听歌差异
- **能量曲线** — 一天各个时段的音乐节奏能量
- **歌荒预警** — 常听歌曲耗尽时的智能提示
- **连续听歌** — 连续听歌天数记录（Streak）
- **月度趋势** — 每月听歌量变化趋势
- **流派演变** — 数月间音乐品味的变化轨迹
- **报告说明** — 内置使用帮助，解释每个指标的含义

**适用场景：** 🎉 年终回顾听歌数据、📈 发现音乐品味变化、💭 了解个人听歌规律

---

### 🤖 AI 歌单系统

用 AI 自动生成个性化歌单，支持多 AI 平台：

**AI 歌单生成**
- 支持 DeepSeek、OpenAI、Kimi、阿里通义等多种 AI 模型
- 自定义 AI 连接配置（API Key、Base URL、模型选择）
- 基于听歌历史自动生成主题歌单

**歌曲知识库系统**
- 批量为音乐库生成 AI 特征（加速后续推荐）
- 网络中断自动续接，无需重新开始
- 新增歌曲时自动增量更新，无需重复处理
- **知识库导出/导入** — 以 JSON 文件共享，多设备/多人协作时省去重复生成的 API 费用

**配置入口**
- 在「设置」新增独立「AI 歌单」Tab
- 实时进度显示、生成原理说明

**适用场景：** 🎵 快速生成主题歌单、👨‍👩‍👧‍👦 家庭/团队共享知识库、💰 降低 API 调用成本

## 🎨 UI 与国际化优化

### 中文适配

- **完整中文翻译** — 补全原版缺失的 168 + 15 个条目
- **流派本地化** — 自动转换为中文（Pop → 流行、Rock → 摇滚、Classical → 古典等）
- **术语统一** — 歌手、歌曲、专辑、播放列表等术语统一为符合习惯的表述

### 播放器界面优化

- **歌词入口重新设计** — 从顶部 header 移到歌名旁，与歌名对齐（歌词 / 车载 / + / ♡）
- **音量条移除** — 播放页下方不再显示音量滑动条，简化界面
- **Android 全屏适配** — Edge-to-edge 模式，底部系统手势条透明化处理
- **音乐库滑动切换** — 收藏/专辑/艺术家/歌曲四个 Tab 支持左右滑动切换，带过渡动画

### 大规模国际化（28 种语言）

- **歌单管理** — 多选移除、重新排序、批量下载等操作界面
- **全部歌曲排序** — 排序菜单完整翻译
- **收藏功能** — 点赞、收藏提示完整翻译
- **电台界面** — 流媒体电台相关文案
- **登录错误** — 分类错误提示（网络错误、认证失败、服务器错误等）
- **主题编辑器** — 5 个 Tab、所有控件的标签和说明
- **自定义组件** — Flutter 代码编辑器的所有提示和帮助文本

## 运行

```bash
flutter pub get
flutter run
```

构建 release APK（arm64）：

```bash
flutter build apk --release --target-platform android-arm64
```

## 连接服务器

1. 启动应用
2. 输入服务器地址（如 `https://your-server.com`）
3. 输入用户名和密码
4. 如果使用旧版服务器，开启"旧版认证"
5. 点击"连接"
